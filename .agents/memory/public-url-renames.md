---
name: Public URL renames
description: Why Neutaware keeps legacy URLs when changing public-facing solution categories
---

When a public Neutaware category is renamed, move navigation and the sitemap to the new canonical path while keeping a redirect from the previous path.

**Why:** Existing bookmarks and inbound links should continue to reach the same content without maintaining duplicate public pages.

**How to apply:** For future category or service URL changes, update links and metadata to the new path and retain a working redirect from the old one.
